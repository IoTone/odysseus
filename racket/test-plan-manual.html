Before you start — one-time setup (Linux dev box)

Install the official Racket (not Homebrew on Linux), put it on PATH, install deps, and build:

copyracket/install-racket.sh
export PATH="$HOME/racket/bin:$PATH"
raco pkg install --auto --skip-installed web-server-lib db-lib
raco pkg install --link racket/pkgs/cli-kit racket/pkgs/db-kit racket/pkgs/web-kit
cd racket && raco make config.rkt cli/*.rkt domain/*.rkt server/*.rkt test/*.rkt

On macOS / Windows, follow the per-OS runbook in VALIDATION.md (PowerShell needs the explicit file list above — it won't expand *.rkt).

All commands below assume you are in the racket/ directory with that PATH set, unless a step says otherwise. Pass only when the actual output matches Expected.
